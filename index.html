ℹ️ 关于昭朝工作台

版本：v3.0 邮箱登录+管理后台版
形态：西高地白梗小狗 🐶
技术栈：HTML/CSS/JS + Chart.js + localStorage + Supabase（可选）
数据存储：浏览器 localStorage 优先，可选云同步（登录隔离）
追踪数据：体重 · 习惯 · 记账 · 阅读 · 工作 · 饮食（饭搭子）
信息聚合：天气 · 热搜 · 快捷入口
Echo Diary：?diary=1 导出当日日记数据（供快捷指令/LLM 使用）
主题：8 套风格包（灵感源自不一书个人工作台生成器）
部署：可托管在任何静态服务（CloudStudio / GitHub Pages / Vercel）
